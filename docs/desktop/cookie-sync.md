# Cookie 同步设置

LX-M Music 新增「设置 → Cookie 同步设置」面板，可为 **五大平台** 分别配置 Cookie，实现播放记录与收藏歌单的同步。

> ⚠️ **重要：Cookie 不会用于「高音质解锁」。**
> 
> 高音质请通过「基本设置 → 自定义源」配置音源，详见 [自定义音源](./custom-source.md)。

## 支持平台

| 平台 | 关键 Cookie 字段 | 同步内容 |
|------|----------------|---------|
| 网易云音乐 | `MUSIC_U` / `__csrf` | 「我喜欢的音乐」 |
| QQ 音乐 | `uin` / `qqmusic_key` | 自建歌单 |
| 酷狗音乐 | `kg_mid` / `kg_user_v` | 「我喜欢」 |
| 酷我音乐 | `kw_token` | 「我喜欢的歌单」 |
| 咪咕音乐 | `migu_music_sid` | 收藏 |

## 如何获取 Cookie

### 网易云音乐

1. 打开 [music.163.com](https://music.163.com) 并登录
2. 按 `F12` 打开开发者工具 → Application → Cookies
3. 找到 `MUSIC_U` 和 `__csrf` 字段，复制值
4. 在 LX-M Music「Cookie 同步设置 → 网易云音乐」中粘贴

### QQ 音乐

1. 打开 [y.qq.com](https://y.qq.com) 并登录
2. 按 `F12` → Application → Cookies
3. 找到 `uin` 和 `qqmusic_key` 字段

### 其他平台

类似方式，在对应平台网页版登录后，从开发者工具 Cookies 中提取关键字段。

## 同步开关

每个平台提供两个独立开关：

### 播放记录同步

- 每首歌播放完成后上报到对应平台
- 影响平台「每日推荐」等个性化算法
- 建议开启以获得更精准的音乐推荐

### 收藏歌单同步

- 本地收藏的歌曲定期上报到对应平台「我喜欢」歌单
- 双向同步：本地收藏 ↔ 平台歌单
- 首次同步可能需要一些时间

## 隐私说明

- Cookie **仅存储在本地**，不会上传到任何服务器
- 同步请求直接发往对应音乐平台官方 API
- 可随时在设置中关闭同步或清除 Cookie

## 常见问题

### Q: Cookie 失效了怎么办？

A: Cookie 通常有有效期，失效后需要重新获取并更新。建议：
1. 定期重新登录网页版获取最新 Cookie
2. 关注 Cookie 过期提醒（如有）

### Q: 同步失败怎么办？

A: 请检查：
1. Cookie 是否正确完整
2. 网络连接是否正常
3. 对应平台 API 是否变动

### Q: 会泄露我的 Cookie 吗？

A: 不会。Cookie 仅存储在本地配置文件，所有同步请求直接发往官方 API，不经过第三方服务器。
