# 自定义音源

LX-M Music 内置的 kw / kg / tx / wy / mg 等音源默认只能拿到 128k 音频。更高音质需要由用户手动导入「自定义源」来代理播放链接请求。

## 什么是自定义音源

自定义源脚本本质上是一个 **HTTP 代理**：

1. LX-M Music 把歌曲信息（songmid / hash）和期望音质告诉脚本
2. 脚本去对应平台「带 VIP Cookie 请求」拿到高音质音频直链
3. 将直链返回给 LX-M Music 播放

## 如何启用高音质

### 方法一：在线导入（推荐）

1. 打开「设置 → 音源 → 预设音源链接」
2. 点击「复制链接」按钮，复制任一音源链接
   - 推荐：SixYin、Huibq 等社区维护的音源
3. 打开「设置 → 基本设置 → 自定义源 → 自定义源管理」
4. 选择「在线导入」→ 粘贴链接 → 确认
5. 回到「基本设置」选择刚导入的音源作为当前音源
6. 在「设置 → 播放设置 → 优先播放的音质」中选择目标音质：
   - 128k / 320k / flac / flac24bit / hires / atmos / master

### 方法二：本地导入

1. 获取自定义源脚本文件（`.js`）
2. 打开「设置 → 基本设置 → 自定义源 → 自定义源管理」
3. 选择「本地导入」→ 选择脚本文件 → 确认

## 支持的音质

| 音质 | 说明 | 需要音源支持 |
|------|------|-------------|
| 128k | 标准音质 | 所有音源 |
| 320k | 较高音质 | 大部分音源 |
| flac | 无损音质 | 部分音源 |
| flac24bit | 24bit 无损 | 少数音源 |
| hires | 高解析度 | 少数音源 |
| atmos | 杜比全景声 | 极少数音源 |
| master | 母带音质 | 极少数音源 |

## 自定义源 vs 扩展音源插件

| 项目 | 自定义音源 | 扩展音源插件 |
|------|-----------|-------------|
| 安装方式 | 用户手动导入脚本 | 由加载器动态注入 |
| 定位 | 为内置 5 大平台换高音质直链 | 注册主程序未内置的独立音源 |
| 平台覆盖 | kw/kg/tx/wy/mg | 由插件自行定义 |
| 更新方式 | 依赖音源作者维护 | 更新插件即可 |
| 主仓库耦合 | 无接口逻辑 | 无接口逻辑（彻底解耦） |

## 常见问题

### Q: 为什么 Cookie 不能解锁高音质？

A: 本项目中的 Cookie **仅用于同步**（播放记录、收藏歌单），不用于请求高音质直链。高音质解锁完全依赖自定义音源脚本的代理能力。

### Q: 音源失效了怎么办？

A: 自定义音源由第三方维护，接口变动时可能失效。请：
1. 关注音源作者的更新
2. 尝试更换其他音源
3. 在 GitHub Issues 中反馈
