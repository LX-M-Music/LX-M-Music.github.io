# 杀毒软件报毒

## 为什么会报毒？

LX-M Music 基于 Electron 构建，部分杀毒软件可能会误报：

1. **Electron 框架本身**：某些杀软对 Electron 打包的应用有白名单机制
2. **网络请求行为**：软件需要访问网络获取音乐信息
3. **文件读写行为**：需要读写本地配置文件和缓存

## 如何处理？

1. **确认下载渠道**：请确保软件是从 [GitHub Release](https://github.com/Miao-moe/lx-m_lx-Miao-moe-music-desktop/releases) 或本官网下载的
2. **添加白名单**：在杀毒软件中将 LX-M Music 添加到白名单/信任列表
3. **更换杀软**：如果频繁误报，建议更换为更智能的杀毒软件

## 安全声明

- 我们不对第三方渠道下载的软件安全性作任何保证
- 所有发布版本均通过 GitHub Actions 自动构建，构建日志公开可查
- 源码完全开源，可自行审计

## 验证签名

Windows 版本的安装包带有代码签名（如有），可在文件属性中查看数字签名信息。
