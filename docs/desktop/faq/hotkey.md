# 快捷键说明

## 全局快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Alt + F` | 显示/隐藏主窗口 |
| `Ctrl + Alt + →` | 下一首 |
| `Ctrl + Alt + ←` | 上一首 |
| `Ctrl + Alt + ↑` | 音量增加 |
| `Ctrl + Alt + ↓` | 音量减少 |
| `Ctrl + Alt + Space` | 播放/暂停 |

> 全局快捷键可在「设置 → 快捷键」中自定义。

## 播放页快捷键

| 快捷键 | 功能 |
|--------|------|
| `Space` | 播放/暂停 |
| `→` | 快进 5 秒 |
| `←` | 后退 5 秒 |
| `↑` | 音量增加 |
| `↓` | 音量减少 |
| `L` | 切换歌词显示 |
| `M` | 静音/取消静音 |

## 设置页快捷键（LX-M 新增）

| 快捷键 | 功能 |
|--------|------|
| `Alt + →` | 下一个设置面板 |
| `Alt + ←` | 上一个设置面板 |

## 列表快捷键

| 快捷键 | 功能 |
|--------|------|
| `Delete` | 从列表中移除选中歌曲 |
| `Ctrl + A` | 全选 |
| `Ctrl + 点击` | 多选 |
| `Shift + 点击` | 范围选择 |
