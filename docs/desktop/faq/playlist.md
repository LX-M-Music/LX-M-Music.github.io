# 音乐播放列表机制

## 播放列表与试听列表

LX-M Music 中有两个列表概念：

### 试听列表

- 搜索、歌单详情页点击歌曲后，歌曲会进入试听列表
- 试听列表是临时的，切换歌单或搜索时会清空
- 试听列表中的歌曲可以添加到「我的列表」

### 我的列表

- 用户自己创建的歌单，数据持久化存储
- 支持导入/导出为 `.lxmc` 格式
- 可以设置默认播放列表

## 播放模式

| 模式 | 说明 |
|------|------|
| 列表循环 | 顺序播放，到末尾后回到开头 |
| 列表随机 | 随机打乱播放顺序 |
| 单曲循环 | 重复播放当前歌曲 |
| 顺序播放 | 顺序播放，到末尾后停止 |

## 音质切换

在播放列表中右键点击歌曲，可选择「切换音质」，支持：

- 128k / 320k / flac / flac24bit / hires / atmos / master

> 实际可用音质取决于当前音源支持情况。
