# 歌曲换源

当某首歌在当前平台无版权、下架或音质不佳时，可以把歌曲**替换到其他平台的同一首歌**。

## 使用方法

1. 右击歌曲名或歌曲行，选择「歌曲换源」
2. 软件按**歌名、歌手、时长**筛选匹配候选版本，并优先打开有匹配歌曲的平台
3. 找不到时，可取消「仅显示匹配版本」查看其他平台的搜索结果
4. 点击候选的试听按钮可先试听并选中该候选
5. 确认后歌曲在**原位置替换**，播放与下载都会使用新的音源

## 行为细节

- 切换平台会清空旧选择
- 保存失败时保留原曲
- 歌手头像、简介等信息由平台提供，缺失时显示占位内容
- 默认按歌名 + 歌手 + 时长匹配，匹配不到时可放宽条件浏览全部搜索结果

## 常见问题

**Q：为什么某些歌换源后播放仍然失败？**
A：换源只改变元数据与音源平台，播放仍依赖自定义音源脚本能取到该平台歌曲的播放地址。请确认音源脚本可用（见[自定义音源](/docs/custom-source)）。

**Q：换源列表为空？**
A：目标平台可能确实没有这首歌，或平台接口临时异常。可稍后重试或手动搜索确认。
