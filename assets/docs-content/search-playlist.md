# 搜索与歌单

## 支持平台

**酷我 · 酷狗 · QQ 音乐 · 网易云 · 咪咕**

- 支持搜索歌曲、歌单、歌手、专辑（具体类型以平台支持为准）
- 点击列表中的歌手或专辑信息可进入独立详情页
- 在线歌单、排行榜、推荐歌单、我的列表、播放队列
- 设置 → 列表设置：歌曲列表与下载列表支持 **20-100 px** 封面大小
- 右键歌名或歌曲行打开菜单，可进行歌曲换源等操作
- 按设置显示平台原名或别名
- 部分列表提供重试入口；页面异常时可通过错误页重试或切页恢复

## 封面与列表加载

| 功能 | 说明 |
| --- | --- |
| 本地歌单 | 歌曲数据保存在本地；增删歌曲、调整顺序会同步保存 |
| 列表复用 | 优先复用已读取的数据，启动时预读取上次选中的列表 |
| 平台分组 | Cookie 导入的歌单按平台分组，支持折叠并记住展开状态 |
| 拖动排序 | 长按约 450 ms，或按住 Ctrl / Command 拖动；限当前分组内 |
| 封面加载 | 按可见区域与显示尺寸加载，合并重复请求；缩略图失败时尝试原图 |
| 列表加载方式 | 设置 → 列表设置，可选择列表与首屏封面一起显示（默认），或先显示列表再逐一加载封面 |
| 缓存管理 | 设置 → 其他设置 → 资源缓存，可查看和清理 |

封面缓存达到约 **256 MiB 或 10,000 条记录**时清理较早写入的内容；清理资源缓存不会删除本地歌单。

## 播放整个歌单或排行榜

- 在线列表内的歌曲需添加到「我的列表」才能播放：全选列表歌曲后添加到现有列表或新建列表
- 从 v1.10.0 起，右击排行榜名字可直接播放或收藏整个排行榜
- 歌单详情页可点击播放按钮临时播放，或收藏后再播放
- v1.18.0+ 可开启「双击列表歌曲时自动切换到当前列表播放」

## 打开外部歌单

- **不支持跨源打开歌单**：确认歌单平台与软件右上角所选歌单源一致
- 分享歌单打开失败时，可先在浏览器打开，再复制地址栏 URL 到软件
- 已知歌单 id 可直接输入 id 打开

### 打开网易源「我喜欢」歌单

网易「我喜欢」需要登录。拼接格式：`[id|url]###token`，例如：

```
https://music.163.com/#/playlist?id=11332&userid=123456###xxxxxx
11332###xxxxxx
```

token 获取方法（`token` 是账号临时身份令牌，注意保密）：

1. 浏览器登录网易云音乐后按 `F12` 打开开发者工具
2. Chrome 系：应用程序(application) → Cookies → `https://music.163.com` → 找到名为 `MUSIC_U` 的行，其值即为 token
3. Firefox：存储 → Cookie → 同上找 `MUSIC_U`

## 更新已收藏的在线歌单

仅对从歌单详情页点「收藏」收藏的歌单有效：右击已收藏列表名 → 「更新」。

注意：这会用最新的在线列表**覆盖**本地列表。

## 实用快捷操作

- 右击播放栏歌曲封面：定位当前播放的歌曲
- 右击播放栏进度条上的 `LRC` 按钮：锁定/解锁桌面歌词
- 搜索框、歌单链接输入框内右击：粘贴剪贴板内容
- 右击单条搜索历史：移除
- 选中列表文字后右击：复制
- 双击播放详情页：关闭详情页
- 左击播放栏歌曲名：复制
- 右击设置-主题设置的「道法自然（Auto）」主题：打开亮暗主题设置
- 歌单详情页按退格键：返回歌单列表
- `F11`：进入/退出全屏（v1.19.0+）
- 添加歌曲弹窗中按住 `Ctrl` 点击列表名：不关闭窗口，方便添加到多个列表（v1.22.0+）

macOS 上 `Ctrl` 对应 `Command` 键。
