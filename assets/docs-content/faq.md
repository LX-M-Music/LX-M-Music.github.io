# 常见问题

## 歌曲无法试听与下载

### 所有歌曲提示「请求异常😮，可以多试几次…」

尝试更换网络（如切换到手机热点）；家庭网络可尝试将光猫断电 5 分钟再通电。

### 提示 `getaddrinfo EAI_AGAIN` 或「无法连接到服务器」

可能是 DNS 问题：

1. 将 DNS 改为自动获取
2. 或手动设置 DNS 为 `223.6.6.6` / `8.8.8.8`（不要用 360 DNS）

改完可能需要清理系统 DNS 缓存并重启软件。

### 通用解决顺序

1. 更新到最新版本
2. 切换其他歌曲验证是否全部失败
3. 设置 → 音乐来源，切换其他接口
4. 切换网络（手机热点）
5. 查看上游 issue #5 确认接口状态

### Windows 所有歌曲提示「音频加载错误，5秒后切换下一首」

关闭 Internet 选项的代理设置：`Win+R` 输入 `inetcpl.cpl` → 连接 → 局域网设置 → 去掉代理服务器及自动配置的勾选。

## 软件无法联网

- 检查设置内是否开启了代理（配置错误会导致无法联网）
- 检查软件是否被第三方软件/防火墙阻止

## 界面异常

### Windows 10/11 界面异常或无法显示

添加运行参数 `--disable-gpu-sandbox` 启动；无效时依次尝试 `--no-sandbox`、`-dha`、`--disable-gpu`。

注意：这些参数会禁用部分安全特性或降低性能，没有问题不要使用。

任务栏有进程但无窗口的，可尝试更换安装目录（安装版需卸载后换目录重装）。

### Windows 7 界面异常

- 未开启 Aero 主题时透明窗口无法工作，请开启 Aero 效果（任务栏变透明）
- 或添加参数 `-dt` 以非透明模式启动
- 安装 `.NET Framework 4.7.1` 或更高版本可解决启动后无界面的问题
- 界面整体闪烁：切换到系统内置 Aero 主题

### Linux 界面异常

添加启动参数 `-dha` 禁用硬件加速（v1.6.0+）。

## 安装问题

### 安装失败，提示「安装程序并未成功地运行完成」

- 控制面板卸载所有旧版本残留后重装
- 清理安装路径残留文件
- 清理注册表（建议用清理工具）

### 升级后旧版被卸载但新版未安装

通常是当初以管理员身份安装、运行时非管理员导致。建议选择**为当前用户安装**并安装到用户目录或其他分区。

### 提示缺少 xxx.dll

以管理员运行 `cmd`，输入 `sfc /scannow`，完成后重启；仍不行请按具体错误信息检索解决方案。

### macOS 提示「已损坏，无法打开」

软件未签名被系统拦截：终端执行

```bash
sudo xattr -rd com.apple.quarantine "/Applications/LX-M Music.app"
```

## 软件更新

- 启动时发现新版本会自动下载安装包并提示更新（详见 [Windows 自动更新](/docs/auto-update)）
- **绿色版**自动更新不可用，建议使用安装版
- **macOS / Linux** 版不支持自动更新，需手动下载覆盖

## 杀毒软件报毒

作者仅保证代码不含恶意行为且完全开源，安装包由 CI 构建可查日志。第三方依赖存在供应链攻击可能时软件会受牵连。前提是从**官方渠道**下载的安装包。是否继续使用请自行判断。

## 歌曲下载失败，提示 `ENOENT: mkdir`

更换下载歌曲目录（一般是设置的下载目录无读写权限）。

## 使用时耳机意外关机

漫步者部分型号耳机有此反馈，可尝试添加 `-dhmkh` 启动参数。

## Windows 7 桌面歌词字体列表为空

需要安装 PowerShell 5.1 及以上版本。当前版本可在 PowerShell 窗口输入 `Get-Host` 查看。
