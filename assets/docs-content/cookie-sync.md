# Cookie 同步

入口：**设置 → Cookie 同步设置**。

## 登录方式

- **手动填写 Cookie**
- **一键登录**：需要系统默认浏览器支持 Chromium 自动化；无法完成时可手动填写

## 平台能力矩阵

| 平台 | 自建歌单导入 | 歌单修改回传 | 播放记录上报 |
| --- | :---: | --- | :---: |
| 网易云 | ✓ | 歌曲增删、改名、歌曲排序 | ✓ |
| QQ 音乐 | ✓ | 歌曲增删 | ✓ |
| 酷狗 | ✓ | 歌曲增删 | ✓ |
| 酷我 | ✓ | 暂不支持 | — |
| 咪咕 | ✓ | 歌曲增删、改名 | — |

## 主要设置

| 设置或操作 | 作用 |
| --- | --- |
| 测试获取歌单 | 检查登录状态、显示歌单数量；不修改本地歌单 |
| 立即同步 | 将平台自建歌单及歌曲导入「我的列表」 |
| 同步平台自建歌单到本地 | 开启后软件启动时自动同步一次 |
| 将播放记录同步回平台 | 自然播放完成或自动衔接下一首时上报；同一首歌 30 分钟内去重 |
| 推荐歌单 | 支持的平台携带 Cookie 请求推荐，内容由平台返回 |

## 歌单修改回传

在「我的列表 → 列表更新管理」中为歌单开启「同步修改到平台」（默认关闭）。需要：

- 保存对应平台的**有效 Cookie**
- 歌单必须属于当前账号（网易云「我喜欢的音乐」等特殊歌单暂不支持）

行为说明：

- 开启时建立同步基准，仅回传之后的修改，已有本地修改不会追溯上传
- 只同步同平台歌曲，其他平台和本地歌曲不会上传
- 回传歌曲增删时保留平台端独立添加的歌曲
- 改名或排序在两端发生不同修改时**暂停并提示核对**；不支持的改名、排序仅在本地生效
- 待回传或回传失败时暂停云端覆盖本地列表；修改和进度保留，重启、恢复联网或点「立即回传」可重试
- 拉取期间的新编辑不会被覆盖
- 删除本地歌单仅解除关联，不删除平台歌单
- 回传关闭时，手动或自动拉取仍以平台内容覆盖本地副本；未回传的修改可能被覆盖

## 注意事项

- Cookie 字段齐全不代表登录仍有效，可通过「测试获取歌单」确认
- 播放记录上报失败不影响播放
- **Cookie 仅用于同步**，不解锁高音质；高音质请通过「自定义音源」配置（见[自定义音源与音质](/docs/custom-source)）
