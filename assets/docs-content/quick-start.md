# 快速上手

## 界面总览

主界面包含：左侧导航（搜索、歌单、排行榜、我的列表、设置）、中间内容区、底部播放栏。点击播放栏的封面或歌名可进入播放详情页；再次双击详情页或按 Esc 可返回。

## 搜索音乐

1. 左侧选择「搜索」
2. 顶部切换音源平台（酷我 / 酷狗 / QQ / 网易云 / 咪咕）
3. 输入关键词回车，可搜索**歌曲、歌单、歌手、专辑**（具体类型以平台支持为准）
4. 点击搜索结果中的歌手或专辑名称，可进入独立的歌手 / 专辑详情页

搜索框候选内容可用键盘上下方向键选择，回车搜索已选内容。

## 播放歌曲

- 单击歌曲行的播放按钮或双击歌曲行试听
- 默认情况下播放搜索/歌单/排行榜的歌曲会先加入「我的列表」的试听列表
- 想连续播放多首：使用 `Ctrl` / `Shift` 多选后添加到「我的列表」播放（多选方法见下）

## 播放列表机制

1. 播放搜索列表、歌单列表、排行榜列表的歌曲时，自动将该歌曲添加到「我的列表」试听列表后再播放
2. 「稍后播放」是一个优先级最高的特殊队列，点击「下一曲」会消耗该队列的歌曲
3. 切歌时若不通过「上一曲 / 下一曲」（如直接点击列表中的歌曲），稍后播放队列会被清空
4. v1.18.0+ 新增「双击列表歌曲时自动切换到当前列表播放」设置，默认关闭，仅对歌单、排行榜有效

## 收藏与歌单管理

- 歌单详情页点击「收藏」可将歌单收藏到「我的列表」
- 右击排行榜名字可直接播放或收藏整个排行榜
- 本地歌单的歌曲数据保存在本地，增删与排序会同步保存
- 按住 `Ctrl`（macOS 为 `Command`）进入拖动模式，可拖动调整列表顺序
- 在我的列表按 `Ctrl + F` 可搜索列表内歌曲，`Ctrl + Enter` 跳转并播放

## 多选操作

按住 `Shift` 或 `Ctrl` 再点击即可多选（类似 Windows 文件选择）：

- `Shift`：连续选择（点第一项，再点第五项即选中 1-5）
- `Ctrl`：不连续选择
- `Ctrl + A`：全选
- 多选后右击弹出菜单可批量操作；不按修饰键点击任意一项即取消全部选择

macOS 上 `Ctrl` 对应 `Command` 键。
