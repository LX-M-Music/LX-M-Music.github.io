# 扩展音源插件与插件商店

## 设计理念

第三方平台音源**不再内置进主程序**，而是以**独立插件**形式存在：

- 主程序保持「干净的播放器」定位
- 插件可单独托管、单独更新
- 运行时由加载器动态注入
- 接口失效时**只需更新插件，无需主程序发版**

## 插件商店

入口：**设置 → 插件商店**。官方插件来自应用仓库 GitHub `master` 分支，可一键安装、更新与卸载。

## 与自定义源的区别

| | 自定义源 | 扩展音源插件 |
| --- | --- | --- |
| 定位 | 提供播放地址（musicUrl） | 更大粒度的功能扩展 |
| 管理入口 | 设置 → 自定义源管理 | 设置 → 插件商店 |
| 分发 | 用户手动导入脚本 | 商店一键安装 |
| 面向 | 普通用户 | 普通用户 + 开发者 |

## 开发者：扩展音源加载器

开发者扩展音源通过 `window.__lxExtSourcePlugins__` 全局对象接入：

| 项目 | 说明 |
| --- | --- |
| 配置入口 | `window.__lxExtSourcePlugins__` |
| 加载方式 | 本地工厂函数或远程脚本 |
| 界面关系 | 独立于「自定义源管理」，当前没有单独的插件管理面板 |
| 集成要求 | 自行适配搜索、歌单等调用 |
| 参考资料 | 应用仓库 `ext-source-plugins/README.md`、加载器代码 `src/renderer/utils/musicSdk/plugins/loader.js` |
