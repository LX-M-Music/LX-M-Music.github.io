# 播放增强

## 无缝衔接播放（Gapless Playback）

- **双 audio 引擎交叉淡化**：避免歌曲切换时的音频中断
- 支持**渐入渐出**（Fade-in / Fade-out）：切歌音量平滑过渡，持续时间 **100-3000ms** 可调

## 平滑动画

- 全局 CSS 动画系统，动画速率 **0.5x-1.5x** 可调
- 页面切换与播放详情页动效平滑过渡

## 设置页快捷键

- `Alt + ←` / `Alt + →`：切换上一个 / 下一个设置面板

## 其他

- **音频输出设备切换**：设置中选择输出设备（v0.17.0+；该功能可能让安全软件提示访问摄像头，实际不会用到，可选择阻止）
- **自动衔接下一首**：自然播放完成时自动播放下一首，并触发播放记录上报

## 播放详情页

- 双击播放详情页可关闭
- 播放详情页动效与页面切换共用动画系统
