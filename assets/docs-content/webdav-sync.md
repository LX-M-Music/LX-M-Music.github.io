# WebDAV 数据同步

入口：**设置 → 数据同步 → WebDAV 同步**。它与设备间的服务端 / 客户端同步分别启用。

## 配置步骤

1. 填写 WebDAV 服务器地址、用户名、密码（或应用专用密码）和相对目录。LXM 其他同步项目默认放在 `lx-music`，手机版歌单默认放在 `LX_Music`。手机版改过 WebDAV 路径时，把「手机版歌单目录」填成相同相对路径
2. 保存配置并测试连接（会在目标目录创建、读取并删除随机临时文件验证读写权限）
3. 启用 WebDAV，分别开启需要同步的项目
4. 首次使用：在有数据的设备上选择「上传到云端」，另一台设备选择「从云端下载」；之后可「立即同步」或开启自动同步

## 可同步项目

| 项目 | 同步内容 |
| --- | --- |
| 歌单 | 试听列表、我的收藏、自建及收藏歌单的名称、来源、歌曲和顺序；Cookie 导入歌单与临时列表保留在本机 |
| 下载历史 | 已完成记录；不传输音乐文件 |
| 下载任务 | 未完成任务的歌曲、音质、文件名；恢复后暂停，开始下载时重新获取地址 |
| 系统设置 | 播放、界面、歌词、下载行为等常规设置 |
| 不喜欢列表 | 不喜欢规则 |

每项独立开关。关闭某项会停止该项双向同步，保留本机和云端已有内容。WebDAV 连接信息、平台 Cookie、代理、自定义音源选择等本机配置不会随系统设置同步；快捷键、自定义音源文件、主题文件和音乐文件不在同步快照内。

## 自动同步

应用启动完成、重新启用或修改连接配置后约 10 秒执行首次检查，之后按间隔运行（默认 5 分钟，可设 1-1440 分钟）。离开设置页仍会同步，退出应用后停止；离线时跳过，恢复联网后重新安排。

## 冲突处理

同步按项目比较上次成功同步的本机与云端内容：

- 只有一端修改：传递该端数据
- 两端都修改了同一项：停止本次同步并提示冲突
- 首次同步时本机该项为空会接收云端内容；两端已有不同内容需选择上传或下载

替换本机数据前会在应用数据目录保留 `webdav-local-backup.json`（最近一次覆盖前的副本）。

## 与手机版互通

与 `lx-lxwalnut-music-mobile` 互通自建歌单、试听列表和我的收藏时：

1. LXM 中只勾选「歌单」
2. 「手机版歌单目录」设置为手机版 WebDAV 路径（默认 `LX_Music`）
3. 各平台通过 Cookie 自动导入的歌单保留在本机，不参加共享同步

## 技术细节

- 歌单使用手机版兼容的 `playlists.json`（格式版本 2）；LXM 其他项目使用 `lx-music-sync.json`（版本 1）
- 单个文件最多 32 MiB；支持 HTTP/HTTPS 与 Basic 认证，HTTPS 使用正常证书验证
- 请求在主进程执行，不受浏览器 CORS 限制；使用直接连接，不套用音乐请求代理
- 上传采用 HTTP 条件请求（If-None-Match / If-Match / Last-Modified）；跨站重定向会被拒绝，凭据不会转发
