# 流动背景与封面缓存

## 流动背景

以**当前歌曲的专辑封面**生成流动背景（基于 [kawarp](https://github.com/better-lyrics/kawarp) 的 `@kawarp/core`）：

- 在「设置 → 高级」中可调整性能挡位或关闭背景
- 暂停时逐渐静止，窗口隐藏时停止绘制，遵守软件内的动画开关
- 没有可用封面时显示主题底色，背景不读取音频数据

「按钮颜色跟随动态背景」默认关闭：开启后采样现有背景画面，按钮根据所在区域颜色随背景流动变化，并自动调整选中项和文字选区的对比度；关闭后恢复当前主题配色。

首页、歌词页及弹窗共用一张背景和同一套采样，暂停或隐藏窗口后保持持续采样。

## 封面缓存

| 功能 | 说明 |
| --- | --- |
| 磁盘缓存 | 封面图片与获取到的封面地址保存到磁盘缓存 |
| 按需加载 | 按可见区域与显示尺寸加载，合并重复请求；缩略图失败时尝试原图 |
| 容量上限 | 约 **256 MiB 或 10,000 条记录**时清理较早写入的内容 |
| 管理入口 | 设置 → 其他设置 → 资源缓存，可查看和清理 |
| 使用范围 | 仅复用已保存的资源；未缓存的封面仍需联网，音频不属于封面缓存 |

清理资源缓存**不会删除本地歌单**。
