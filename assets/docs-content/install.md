# 安装指南

## 下载

前往[下载页](/download)获取最新版本。下载页会自动发现多个加速镜像，并用**你自己的网络**实测各镜像延迟，自动预选最快节点；也可以手动切换镜像。

## 安装包类型说明

软件发布页提供多个类型的安装文件：

- 文件名带 `win_` 的是 Windows 系统运行的版本
  - **Setup.exe**：标准安装版，支持自动更新（推荐）
  - **green.7z**：绿色版，免安装，解压即用；自动更新功能不可用
  - **portable.exe**：便携版，单文件免安装，支持自动更新
- 文件名带 `win7_` 前缀的是 **Windows 7/8/8.1 兼容版**（独立构建，详见 [Win7 兼容版](/docs/win7)）
- 以 `.dmg` 结尾的为 macOS 版本
- 以 `.deb`、`.rpm`、`.AppImage`、`.pacman` 结尾的为 Linux 版本

架构说明：

- `x64` 为 64 位，`x86` 为 32 位
- 同时带两者的为集合版，安装时自动根据系统位数选择
- `arm64` 为 ARM 架构版本
- `x86_64` 为合并包，仅作为安装版与单文件版的低优先级候选

## 平台支持

| 平台 | 状态 |
| --- | --- |
| Windows 10 / 11 | 完整支持（推荐） |
| Windows 7 / 8 / 8.1 | 兼容版（Electron 22 独立构建） |
| macOS 10.15+ | 完整支持（Intel 与 Apple Silicon） |
| Linux | 完整支持（deb / rpm / AppImage / pacman） |

## 安装注意

- Windows 安装时建议选择**为当前用户安装**，并安装在不需要管理员权限的目录；选择「为所有用户安装」可能导致升级后旧版本被卸载但新版本未装上
- macOS 首次启动若提示「已损坏，无法打开」，是因为软件没有签名，在终端执行 `sudo xattr -rd com.apple.quarantine "/Applications/LX-M Music.app"` 后输入密码即可
- Linux 下 `.AppImage` 直接赋予执行权限运行即可

## 更新

- 安装版与便携版支持**自动更新**（含绿色版差分更新，详见 [Windows 自动更新](/docs/auto-update)）
- 更新失败通常是无法访问 GitHub 导致，可手动下载最新安装包覆盖安装
- macOS 与 Linux 版本暂不支持自动更新
