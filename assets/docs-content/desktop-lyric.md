# 桌面歌词

## 开启与基本操作

- 入口：播放栏进度条上的 `LRC` 按钮
- 右击 `LRC` 按钮可**锁定 / 解锁**桌面歌词（锁定后歌词窗口不可拖动、不响应鼠标）

## 功能

- **两种歌词布局**：单行 / 双行布局
- **透明与隐藏控制**：可设置歌词窗口透明度
- **尺寸记忆**：调整后的窗口尺寸会被记住
- 迷你播放器同样支持歌词展示

## 已知问题

- **Windows 7**：未开启 Aero 效果时桌面歌词会有问题，见[常见问题](/docs/faq)
- **Windows 7 字体列表为空**：需要安装 PowerShell 5.1 及以上版本才能正常获取系统字体列表
- **macOS 残留阴影**：Electron 的已知 Bug，暂未修复
- **Linux**：桌面歌词问题暂不主动处理，可尝试 `-dha` 参数禁用硬件加速

## 设置

入口：**设置 → 桌面歌词**，可调整字体、字号、颜色、描边等样式。
